# bot/: the CodinGame bot

| file | what |
|---|---|
| `bot.hpp` | `bot::Bot`: the decision logic. Tracker (`engine/tracker.hpp`) + Monte Carlo equity (`cpp/pe7c.hpp`) + the policy. Used by `main.cpp` and by `arena/`. |
| `main.cpp` | CodinGame entry point: `pk::read_obs` on stdin, `Bot::act`, print, flush. `DEBUG` prints per-turn diagnostics and first-turn platform probes to stderr; `PONDER` adds the between-turns thread probe. |
| `pf_tables.hpp` | HU jam/fold Nash thresholds per effective stack, generated by `solvers/export_pf.py` from `solvers/pf.py`. |
| `bot_prev.hpp` | **Frozen** copy of `bot.hpp` (namespaces `prev`, `pf_prev`) made by `arena/freeze.py`: the arena's reference. Never edit by hand. |

## Build and submit

```sh
python3 tools/bundle.py --minify     # build/cg/poker_bundled.cpp (readable) and build/cg/poker_min.cpp (submit this)
```

Both files are compiled with CodinGame's own flags (`-std=gnu++17 -Werror=return-type -g -pthread`, no
`-O`; the sources carry `#pragma GCC optimize("O3")`). Observed: bundled 60,906 chars, minified
27,369 chars, cap 100,000. The minified binary's output on a recorded stdin is identical to the
bundled one (`tools/bundle.py` checks compilation; the output comparison was done by hand with
`sim/poker_sim.py`'s `obs_to_stdin`).

`tools/cg_minify.py` is crossfish's minifier plus `--keep NAMES` (identifiers it must not rename:
nested `std::chrono` names) and a few more std member names (`rfind`, `compare`, `what`, ...).

## M0 policy

1. The tracker replays the hand; on any mismatch it resyncs from the snapshot (never seen in the
   checks: 0 failures on 633k fuzz and 74k real decisions).
2. **HU jam/fold** (heads-up table, preflop, effective stack ≤ 8 BB): SB first in jams or folds by
   `PF_JAM` at the nearest stack point; BB facing a jam calls or folds by `PF_CALL`.
3. Otherwise **equity vs pot odds**: equity = share of the pot against `n_opp` uniformly random
   hands by Monte Carlo (up to 100k trials or the budget; ~60M trials/s in this sandbox), pot odds
   with the real pot (every non-BB player posts the SB).
   - facing an all-in-sized call: call if equity > odds (+0.08 with 3-4 players alive);
   - unopened preflop, not BB: open to 2.5 BB if equity > 0.50 (+0.03 per extra opponent), else
     complete if equity > odds + 0.03, else fold;
   - facing a bet: raise pot if equity > 0.85, call if equity > odds + 0.03, else fold;
   - check available: bet 0.6 pot if equity > 0.62 (+0.04 per extra opponent; BB option 0.55), else check.
4. Output mapping: `CALL`/`CHECK` as offered, `ALL-IN` whenever the amount covers the stack, `BET x`
   ≥ the offered minimum. 0 replaced actions in 1,000 arena games (64,852 decisions).

Diagnostics per decision: `last_trials`, `last_equity`, `last_tag`.

## Probes (first turn, stderr, `DEBUG`)

`probe __cplusplus=... pe_init_ms=... mc_trials_per_s=...` then per turn `turn_ms`,
`since_last_flush_ms`, trials, equity, tag, and `DESYNC:` if the tracker resynced. With `PONDER`
a detached thread spins and each turn prints `ponder_delta`, the counter's progress since the last
turn: non-zero means the process keeps running between turns (open question Q-A1). Run the probe
build once in the CodinGame IDE, then set `PONDER = false` (and `DEBUG = false`) for submissions.
